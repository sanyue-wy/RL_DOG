## 问题描述

### 现象
页面点击"开启渲染"或"关闭渲染"按钮后：
1. 训练进程正常启动（终端有输出）
2. 页面显示"训练中"状态
3. 但各项指标没有数据流入
4. 训练日志为空

### 影响
- 核心指标面板无数据
- 损失函数面板无数据
- 奖励项分解无数据
- 训练日志无输出

---

## 问题分析

### 问题1：Socket.IO 异步调用问题

**根因分析：**

```python
# 问题代码
def _read_output(self):
    for line in iter(self.process.stdout.readline, ''):
        if line:
            # ❌ 在线程中直接调用异步方法
            self.socketio.emit('train_output', {'data': line})
```

- `_read_output` 在 `threading.Thread` 中运行
- `self.socketio.emit` 是 `async` 方法
- 线程中没有事件循环，无法执行异步代码

**影响程度：** 🔴 严重 - 数据完全无法传输

---

### 问题2：输出缓冲问题

**根因分析：**

```python
# 问题代码
self.process = subprocess.Popen(
    cmd,
    stdout=subprocess.PIPE,  # ❌ 默认有缓冲
    bufsize=1,               # ❌ 行缓冲，但 Python 输出也有缓冲
)
```

- `subprocess.PIPE` 默认有缓冲
- Python 的 `print()` 也有输出缓冲
- 训练脚本的输出不会立即发送到管道

**影响程度：** 🔴 严重 - 数据延迟或丢失

---

### 问题3：事件循环问题

**根因分析：**

- Socket.IO 的 `emit` 需要在正确的事件循环中调用
- 线程中没有事件循环
- `asyncio.get_event_loop()` 在线程中可能失败

**影响程度：** 🔴 严重 - emit 调用失败

---

## 解决方案

### 方案选择

| 方案 | 优点 | 缺点 | 推荐度 |
|---|---|---|---|
| A: asyncio.run_coroutine_threadsafe | 保持现有架构 | 需要传递事件循环 | ⭐⭐⭐⭐⭐ |
| B: 改用轮询方式 | 简单可靠 | 实时性差 | ⭐⭐ |
| C: 改用 multiprocessing | 进程隔离 | 复杂度高 | ⭐⭐⭐ |

**选择方案 A**

### 实现细节

#### 修改1：添加异步支持

```python
import asyncio

class TrainManager:
    def __init__(self, socketio=None):
        # ... 其他初始化
        self.loop = None  # 保存事件循环引用
```

#### 修改2：创建同步 emit 方法

```python
def _emit_sync(self, event, data):
    """在线程中同步发送 Socket.IO 事件"""
    if self.socketio and self.loop:
        try:
            asyncio.run_coroutine_threadsafe(
                self.socketio.emit(event, data),
                self.loop
            )
        except Exception as e:
            print(f"[Emit Error] {event}: {e}")
```

#### 修改3：获取事件循环

```python
def start(self, render=False):
    # 获取事件循环
    try:
        self.loop = asyncio.get_event_loop()
    except RuntimeError:
        self.loop = asyncio.new_event_loop()
        asyncio.set_event_loop(self.loop)
```

#### 修改4：禁用输出缓冲

```python
cmd = [
    sys.executable,
    "-u",  # 无缓冲模式
    str(self.project_root / "legged_gym" / "legged_gym" / "scripts" / "train.py"),
    "--task", "rc"
]

self.process = subprocess.Popen(
    cmd,
    stdout=subprocess.PIPE,
    stderr=subprocess.STDOUT,
    universal_newlines=True,
    bufsize=0,  # 无缓冲
    cwd=str(self.project_root),
    env={**os.environ, 'PYTHONUNBUFFERED': '1'}  # 环境变量禁用缓冲
)
```

#### 修改5：使用新方法发送数据

```python
def _read_output(self):
    for line in iter(self.process.stdout.readline, ''):
        if line:
            line = line.strip()
            self._emit_sync('train_output', {'data': line})  # ✅ 使用新方法
            self._parse_and_emit(line)
```
