## 功能规划

### 高优先级 (P0)

#### 1. React 前端重构

**目标：** 提升代码可维护性和用户体验

**技术栈：**
- React 19
- shadcn/ui 组件库
- Tailwind CSS v4
- Recharts 图表库

**收益：**
- 组件化开发，代码复用性高
- 类型安全（TypeScript）
- 更好的状态管理
- 丰富的 UI 组件

**工作量：** 约 2-3 天

---

#### 2. TensorBoard 日志解析

**目标：** 直接读取 TensorBoard 日志文件

**实现方式：**
```python
from tensorboard.backend.event_processing.event_accumulator import EventAccumulator

ea = EventAccumulator(log_dir)
ea.Reload()
scalar_data = ea.Scalars('Train/mean_reward')
```

**收益：**
- 无需解析 stdout
- 数据更准确
- 支持历史数据回看

**工作量：** 约 1 天

---

#### 3. 历史数据持久化

**目标：** 训练数据保存到文件

**实现方式：**
- JSON 文件存储
- SQLite 数据库（可选）

**数据结构：**
```json
{
  "experiment_id": "2026-07-31_001",
  "start_time": "2026-07-31T10:00:00",
  "iterations": [
    {
      "iteration": 100,
      "mean_reward": 12.34,
      "mean_episode_length": 500,
      "losses": {...},
      "rewards": {...}
    }
  ]
}
```

**收益：**
- 训练数据不丢失
- 支持训练对比
- 支持数据导出

**工作量：** 约 1 天
