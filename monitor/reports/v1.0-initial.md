## 背景

用户在训练 12-DOF 四足机器人时，需要实时监控训练效果，包括：
- 核心指标（Mean Reward、Episode Length）
- 损失函数（Value Loss、Surrogate Loss 等）
- 奖励项分解（20+ 项奖励）
- 训练日志

同时需要一键开启/关闭渲染训练的功能。

---

## 功能实现

### 1. 训练控制

| 功能 | 状态 | 说明 |
|---|---|---|
| 开启渲染训练 | ✅ | 启动带渲染的训练进程 |
| 关闭渲染训练 | ✅ | 启动 headless 训练进程 |
| 暂停训练 | ✅ | SIGSTOP 信号 |
| 恢复训练 | ✅ | SIGCONT 信号 |
| 停止训练 | ✅ | SIGTERM/SIGKILL 信号 |

### 2. 数据监控

| 功能 | 状态 | 说明 |
|---|---|---|
| 核心指标面板 | ✅ | Mean Reward、Episode Length、Action Noise |
| 损失函数面板 | ✅ | Value Loss、Surrogate Loss、Estimation Loss、Swap Loss |
| 奖励项分解 | ✅ | 20+ 项奖励实时显示 |
| 训练日志 | ✅ | 实时输出训练日志 |
| 进度条 | ✅ | 迭代进度显示 |

### 3. UI 设计

| 特性 | 说明 |
|---|---|
| 深色主题 | 专业风格，减少视觉疲劳 |
| 响应式布局 | 支持不同屏幕尺寸 |
| 实时更新 | WebSocket 推送，无需刷新 |

## 核心代码说明

### app.py

- FastAPI 应用创建
- Socket.IO 事件处理
- 静态文件服务
- 自动打开浏览器

- 原生 JavaScript 实现
- Socket.IO 客户端
